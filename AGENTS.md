# Project instructions

- Store research, investigations, design notes, and source references in docs/.
- Keep docs/README.md updated when adding or moving documentation.
- Distinguish product goals, proposed designs, verified facts, and measured results. Date external research and link primary sources.
- Do not describe planned functionality or simulated concurrency as implemented or measured behavior.
- Keep credentials, local session logs, personal files, and runtime artifacts out of Git.
- Start with the mathematical proof workflow. Keep changes within the requested scope.
